# Citing NEBCert

If NEBCert helps your research, please cite it. The repository's [`CITATION.cff`](https://github.com/sircalch/nebcert/blob/master/CITATION.cff) is the canonical record; GitHub's "Cite this repository" button uses it.

Version 1.2.2 (2026-11-20) is archived on Zenodo with the DOI [10.5281/zenodo.22217586](https://doi.org/10.5281/zenodo.22217586).

```bibtex
@software{nebcert_1_2_2,
  author  = {Monreal-Hernández, Andrés},
  title   = {NEBCert},
  version = {1.2.2},
  year    = {2026},
  doi     = {10.5281/zenodo.22217586},
  url     = {https://github.com/sircalch/nebcert}
}
```

NEBCert is research software. A PASS from its checks means the checks found nothing wrong; it is not an independent validation of the scientific result. Cite it for what it is: a tool that documents how a calculation was checked.
